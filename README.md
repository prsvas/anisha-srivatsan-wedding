# Anisha & Srivatsan — GitHub Pages

Upload these files/folders to the ROOT of the GitHub repository:

index.html
style.css
script.js
404.html
.nojekyll
assets/

Do not upload a nested parent folder.

Then GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.

The website URL will be:
https://prsvas.github.io/anisha-srivatsan-wedding/

First get the website live. RSVP Google Sheets/Gmail/Drive integration will be configured after the website is confirmed working.

Replace the two placeholders at the top of script.js later:
RSVP_API_URL
WEDDING_WHATSAPP
